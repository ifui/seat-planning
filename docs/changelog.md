## 2026-11-09 · 基线：自由画布版本

**状态**：git 初始提交 `b32d9fd`（`chore: 初始化仓库，提交表格化重构前的可用版本`）。

这一版已经具备：名册/单位/职级、自由画布布局（`ElementCanvas` + 元素内座位槽）、排座规则、座位图、PNG、快照、图表。

**已知问题**（促成后续重构）：

- 排号依赖元素坐标反推，元素错位会导致排号歧义；
- 布局交互不是 Excel 心智：选区、合并、复制粘贴、拖拽宽高都缺失；
- 数据只有 IndexedDB 一个后端，`file://` 下失败即内存模式。

> 该提交之后的所有工作都在表格模型上重做；旧画布代码在 `3fec3b8` 中删除。

## 2026-11-09 · 验收修复轮（本轮）

**用户要求**（三个优先级）：

1. **数据持久化（最高优先级）**：`file://` 下必须真正能保存，不能只提示「数据仅本次有效」；评估并实测 localStorage、自动备份、IndexedDB 降级组合；
2. **未点测交互逐项实测并修复**：拖动列宽/行高、右键菜单、复制粘贴与填充、双击编辑、冻结行列、视角镜像、拖拽换座、导出 PNG、导出 XLSX、JSON 导入导出；
3. **git 分模块提交**，不要一个巨大提交。

### 3.1 持久化

- 在 `src/db.ts` 增加存储层：`StorageMode = 'indexeddb' | 'local' | 'memory'`：
  - 打开时探测一次（`openStorage()`）；
  - IndexedDB 可用 → 走 Dexie `seat-planning-v2`；
  - 失败 → localStorage 单键 `seat-planning:v2`；
  - 再失败 → 内存；
- 启动自动读取、所有写操作落库；`store.ts` 重写为统一 API；
- 侧栏按实际模式显示三种文案；
- 实测（Edge 157 headless，`file://`）：
  - IndexedDB 模式：排座后刷新、关闭浏览器进程重开，`已就座` 仍为 30；
  - 人为让 `IDBFactory.prototype.open` 抛 `SecurityError`：自动降级 localStorage，排座前 0 → 排座后 30，`localStorage` 中该键长度 **16,197 字符（≈16 KB）**，刷新/重启进程后仍为 30；
  - 把 HTML 复制到另一个临时目录、用同一浏览器 profile 打开：仍是 localStorage 模式，`已就座` 仍为 30 → **同 profile 下 `file://` localStorage 跨文件路径共享**；
  - 未采用「自动下载 JSON 备份」作为主方案：浏览器禁止无手势静默下载，且落盘方案已成立；备份保留为手动「全量备份」。

### 3.3 性能实测

| 场景 | 结果 |
|---|---|
| 种子布局（63 个单元格）拖动列宽 10 步 | 5 ms |
