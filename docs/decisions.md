# 默认口径与关键决策

> 本文件集中记录首版采用的默认值，便于后续单点修改。相关实现位置一并标注。

## 1. 主席台规则

| 项 | 默认口径 | 实现位置 |
|---|---|---|
| 以左为尊的参照系 | 就座者面向台下时的左右。画布以观众视角绘制，因此「就座者左侧」在画布上对应 x 增大方向 | `src/engine/seating.ts` `podiumOrder()` |
| 奇数主席台 | 1 号居中，2 号在就座者左侧，3 号在右侧，左右交替外扩 | 同上 |
| 偶数主席台 | 1 号居中偏左（就座者视角），2 号居中偏右 | 同上；可切 `rules.evenCenterSide` |
| 主席台请假 | 留空位（座位保留，不放其他人） | `rules.podiumLeave = 'hold'`，可在项目规则面板切换 |
| 主席台人员来源 | 全名单按「职级 → 单位 → 名单序」排序后由高到低落位；若对主席台区域配置了职级分层，则只从该分层内取人 | `arrange()` 中 stage 队列 |

## 2. 台下与排序

| 项 | 默认口径 | 实现位置 |
|---|---|---|
| 排的顺序 | 画布 y 从小到大（前排在先），按座位 y 中心聚类成排 | `groupRows()` |
| 台下横向填充 | 中间向两侧（观众视角以左为先） | `rules.hallOrder = 'center-out'` |
| 人员总排序 | 职级 `order` ↑ → 单位路径 `order` 字典序 ↑ → 名册名单序 ↑ | `sortCandidates()` |
| 单位分布 | 同单位连续就座 | `rules.unitOrder = 'continuous'`，可切「各单位交替」 |
| 职级分层 | 按排号区间或按区域限定可坐职级；配置后为强约束，不满足的人不占该排 | `TierRule` |
| 人数多于座位 | 多出的人进入「未排到座位」列表并给提示，不覆盖已坐人员 | `ArrangeResult.unassigned` |

## 3. 数据与存储

| 项 | 默认口径 |
|---|---|
| 主存储 | IndexedDB（Dexie），库名 `seat-planning`，表：rosters / layouts / projects / snapshots / settings |
| 迁移 | 「全量备份」导出单个 JSON；「导入备份」按 id 合并写入 |
| 规模目标 | 500 人、50 个项目以内，单文档 < 10 MB |
| 名册方案 | 同一批人的不同版本（方案一、方案二…），各自独立维护职级、单位树与人员 |
| 布局与项目关系 | 布局包只存物理座位，人员分配只存在项目里，同一会场可反复排不同会议 |

## 4. 名单导入

| 项 | 默认口径 |
|---|---|
| Excel 读取 | 首版只取姓名列：优先找含「姓名/名字/人员」的列，否则取每行第一个非空单元格；支持 .xlsx / .xls / .csv |
| 姓名匹配 | 精确匹配 `Member.name` 或 `aliases` |
| 库外姓名 | 进入「待处理」，可逐个「新建人员」（用面板中选择的单位/职级）或「忽略」 |
| 名单默认状态 | 在位（present） |
| 未导入名单 | 项目默认使用全名册中 `active` 的人员 |

## 5. 视觉与交互

| 项 | 默认口径 |
|---|---|
| 主色 | 墨青 `#3D5A6C`；点缀暖铜 `#A4774E` |
| 背景 | 暖灰 `#F6F7F5`，卡片纯白 |
| 字重 | 不超过 500，不使用粗体堆砌 |
| 间距 | 8pt 栅格（4/8/12/16/24/32/48） |
| 字体 | 系统中文栈（PingFang SC / 微软雅黑），不加载外链字体 |
| 职级色板 | 墨青、灰蓝、暖铜、灰绿、灰紫、青灰等 12 色内选取 |

## 6. 构建与离线分发

| 项 | 默认口径 |
|---|---|
| 主产物 | `vite-plugin-singlefile` 内联为单个 `dist/index.html`，双击 `file://` 可直接使用 |
| 备选 | 若后续需要多文件产物，可去掉 singlefile 插件改用 iife 构建 |
| 运行约束 | 不使用运行时 fetch、外链字体或 CDN；所有资源随包内联 |
| 桌面壳 | 首版不做 Tauri / Electron 封装 |

## 7. 导出

| 项 | 默认口径 |
|---|---|
| PNG | 自绘 Canvas，默认 2×，导出用 3× |
| 打印 | 生成同款版面 PNG，注入隐藏 iframe 后调用浏览器打印（A4 横向） |
| 布局包 | `.seatlayout.json`，含 `schemaVersion: "1.0"` |

## 8. 记录

- 视觉与实现遵循 `web-app-development` 插件的 `uicraft` 规范。
- 主席台以外的长条桌、U 型、口字型、签约/表彰等特殊排法不在首版规则内。
